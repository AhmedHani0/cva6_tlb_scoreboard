we need an array:

typedef struct packed {
  logic valid;
  logic [VPN_LEN-1:0] vpn;
  logic [CVA6Cfg.ASID_WIDTH-1:0] asid;
  logic [CVA6Cfg.PtLevels-2:0] is_page;
  logic is_napot_64k;
  logic [HYP_EXT:0] v_st_enbl;
  pte_cva6_t content;
} sb_entry_t;

sb_entry_t sb_q [TLB_ENTRIES];
-------------------------------------------
In the RTL, the update is written when:

update_i.valid & replace_en[i] & !lu_hit_o

Where:
replace_en = replacement enable
one-hot vector selecting which TLB entry receives the update.

PLRU = Pseudo Least Recently Used
replacement policy deciding which entry to overwrite.
For a black-box scoreboard, we should not use internal replace_en.
So the scoreboard should model its own abstract PLRU tree.
That means we add:

logic [2*(TLB_ENTRIES-1)-1:0] sb_plru_tree_q;
logic [TLB_ENTRIES-1:0] sb_replace_en;

we compute the replacement entry in the scoreboard using the same PLRU algorithm, based on the scoreboard’s own hit vector:

logic [TLB_ENTRIES-1:0] sb_hit;

This is still okay because:
We are not reading DUT internal replacement.
We are independently predicting replacement from the abstract model.

Then on update:

for (int i = 0; i < TLB_ENTRIES; i++) begin
  if (sb_replace_en[i]) begin
    sb_q[i].valid   <= 1'b1;
    sb_q[i].vpn     <= update_i.vpn[VPN_LEN-1:0];
    sb_q[i].asid    <= update_i.asid;
    sb_q[i].is_page <= update_i.is_page;
    sb_q[i].content <= update_i.content;
  end
end

for (int i = 0; i < TLB_ENTRIES; i++) begin
